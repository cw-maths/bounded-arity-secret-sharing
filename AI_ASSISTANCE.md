# AI assistance and verification

This project was developed interactively by Christopher Williamson with
substantial assistance from ChatGPT. The assistance included mathematical
discussion, draft proof and exposition development, Lean implementation,
debugging, and repository preparation. This file records that assistance
without attributing a detailed discovery history that has not yet been
independently reconstructed.

Christopher directed the project, asked mathematical and specification
questions, reviewed the sections marked VERIFY in the specification packet,
and ran successive Lean builds and axiom audits. Historical records state
which checks were reported by him and which were run in the assistant's
workspace.

The final source code, pinned dependencies, build results, axiom checks and
kernel replay are the reproducible evidence for formal validity. An AI's
approval, an informal proof draft, or an assistant's statement that a theorem
is correct is not a substitute for those checks. Readers should separately
inspect the definitions and final theorem statements to assess their intended
meaning; see [the review guide](docs/REVIEW_GUIDE.md).

This private review snapshot makes no claim of independent external review,
historical priority for AI-assisted mathematics, or exact reproducibility of
the interactive discovery process. Publication-stage authorship, detailed
contribution history, and licensing can be settled when the project is
prepared for wider release.
